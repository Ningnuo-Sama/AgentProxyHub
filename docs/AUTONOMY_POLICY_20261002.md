# 自治策略（低心智负担模式）

## 默认行为

用户已授权在既定框架内自动运行。系统按以下顺序选择出口：

1. 同国家；
2. 同大区；
3. 其他可用候选中的最高健康/置信度节点。

当前大区映射包括：

- NA：US / CA / MX
- EU：GB / FR / DE / IT / ES / NL / CH / DK
- EA：JP / KR / TW / HK / MO / CN
- SEA：SG / MY / ID / TH
- OC：AU / NZ

## 自动动作

- 节点异常时自动探活、隔离和重新选路；
- 同国/同大区优先自动换绑；
- 保持环境→端口粘性账本；
- 排除 veto、离线、未探活和已锁定冲突端口；
- 写入自治事件和绑定变更事件；
- Hermes 告警可自动通知既定目标“一帆”。

## 仅在以下情况打断用户

- 跨大区换绑；
- 外部付费生成最终提交；
- 新增或变更微信收件对象；
- 删除数据、覆盖凭据或不可逆变更；
- 现有粘性账号与候选策略冲突且无法安全回退。

## 现场状态

- `enabled=true`
- `routing_enabled=true`
- `auto_rebind_enabled=true`
- `hermes_notify_enabled=true`
- `usage_logging_enabled=true`
- 调度器已运行，周期 300 秒；最近健康检查成功。

## 不改变的边界

自治放开不等于取消本地认证、审计、veto、凭据隔离和付费确认。它们是执行事实和回退依据，不是要求用户逐项操作的阀门。
